# TOEFL 每周学习台

双击 `index.html` 即可开始使用。无需安装软件，无外部脚本和字体依赖。离线版的训练、统计、错题、计时和导入导出均可使用；外部材料和 AI 服务需要联网。

## 日常使用

1. 在「本周任务」选择一项，展开材料与步骤。
2. 开始计时；暂停后可继续，刷新网页也会保留计时状态。也可以直接手填用时。
3. 保存学习记录。若一次口语练了两种题型，用时只在一条记录里填写，另一条填 0，成绩分别填写。
4. 训练与复盘都完成后，再点「标记完成」。计时不会自动完成任务。
5. 典型错题按模板填写；AI 提示词复制到 ChatGPT 语音或 Gemini Live。练习结束后让 AI 输出文字 JSON，复制到网页解析、检查、补用时再保存。

第 1 周从 **2026-09-15** 开始，按连续 7 天计算，即 9/15–9/21；第 15 周从 12/22 开始。每天没有固定任务，不统计连续打卡。

每周新增 **420 分钟参考课程量**。未完成任务递延并额外累加：例如欠 120 分钟，下周参考量是 540 分钟。已投入的时间会从递延参考用时扣除，但只有手动完成才移出欠量。投入超过参考时长但未完成的任务仍会显示，即使剩余参考分钟为 0。

日期跨周后，首页默认打开当前周。可以提前或回看任意周。第 15 周后仍保留全部未完成项；不会自动安排考试后的新任务。考前以轻量维护与休息为先，不必清空欠量。

考试日期暂设 **2026-12-26**，依据新东方转述的 2026 大陆考试时间表：
https://toefl.xdf.cn/202512/15051944.html
这不是深圳考位确认；请在 https://toefl.neea.cn/ 核实。设置页可改考试日期，Practice Test 2 的建议窗口随之变化。

## 云同步已配置：开始登录

你的免费 Supabase 项目和数据表已创建，公开连接参数已内置到网页。

1. 在电脑或安卓打开 https://sheep-kt.github.io/toefl-weekly-2026/ 。
2. 进入「同步与设置」，填注册 Supabase 时使用的邮箱，点击「发送登录邮件」。
3. 打开邮件中的登录链接；回到学习台后应显示「已同步」。
4. 另一台设备使用同一个邮箱重复登录，进度会自动合并。

无需再创建学习台密码。Supabase 免费默认邮件服务只发给项目组织成员的邮箱，并有发送频率限制；本项目仅供个人使用，直接用项目所有者邮箱。不要把邮件中的登录链接转发给别人。点击后网页会清理地址栏中的登录令牌。

官网说明：https://supabase.com/docs/guides/auth/auth-email-passwordless

首次登录仍需要你在邮箱中完成身份验证。登录前可以使用本地记录；登录成功后再同步。若使用其他浏览器打开邮件，需要在那个浏览器中使用学习台，或把邮件链接在原浏览器打开。

## 重新部署参考：一次性配置

网页已发布：https://sheep-kt.github.io/toefl-weekly-2026/ 。数据库与登录回跳地址已配置；登录你的学习台账号后才会实际同步。

### 1. 创建免费数据库

1. 访问 https://supabase.com/ ，登录 / 注册，创建 **Free** 项目。无需为了此程序升级付费计划。
2. 在项目的 SQL Editor 新建查询，粘贴同文件夹 `supabase.sql` 全文，执行。
3. 在 Authentication → Users 中添加一个自己的邮箱密码用户，选择确认该用户（如有 Auto Confirm 选项）。这是学习程序的登录账号；项目数据库密码不是这里的登录密码。
4. 在项目 Connect 或 API 设置中找到 Project URL 与 **Publishable key**（或 legacy `anon` key）。
5. 打开学习台「同步与设置」，填 URL、公开密钥、刚创建用户的邮箱密码，登录。

只使用公开 publishable / anon key。**不能把 secret / service_role 密钥放进网页**。配套 SQL 启用 RLS，限制每个用户只能读取和插入自己的记录。

Supabase Free 当前提供 500 MB 数据库空间，本程序只存文字，个人 15 周使用预计足够。低活跃约一周可能暂停；恢复方式与最新免费限制以官方说明为准：
https://supabase.com/pricing
https://supabase.com/docs/guides/platform/free-project-pausing

### 2. 网页已经发布（以下步骤供重新部署参考）

1. 在 GitHub 新建用于此程序的仓库，将 **index.html 和 sw.js** 上传到仓库根目录。不要上传个人备份、成绩或任何登录令牌。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支、根目录，保存。账号和仓库可用性以 GitHub 当前规则为准；GitHub Free 可使用公开仓库的 Pages。
3. 等待 GitHub 提供网页地址。在电脑和安卓 Chrome 中打开同一地址，分别配置同一个 Supabase 项目和用户。
4. 安卓 Chrome 可通过浏览器菜单「添加到主屏幕」创建快捷入口。

第一次在线打开后，`sw.js` 会缓存网页，之后可在离线时打开。若只上传 index.html，在线访问仍可用，但不能保证断网冷启动。下载的单文件 HTML 本身可随时离线使用。

GitHub Pages 是静态网页托管，不承担进度数据库：
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

### 3. 从本地版迁移到在线版

本地文件和在线网址各有独立的浏览器存储。迁移前在本地版「导出完整备份」，在线版「导入备份」，再登录同步。若本地版已成功同步，也可直接在线登录同一账号拉取数据。

同步失败不会删除本地记录。页面顶部显示待同步、同步成功或具体失败信息；联网后自动重试，也可点「立即同步」。账号退出后本地记录保留，已绑定数据只能继续登录原账号，避免把私人进度混入另一个账号。

不同设备的新增记录独立合并。对同一条记录同时编辑，按设备修改时间采用最后版本，完整事件历史保留在备份中；建议设备开启自动校时，并在切换设备前确认同步成功。长时间离线修改同一条记录时，应在两端先导出备份。

## 统计口径

- 学习时间按记录的实际日期统计，不按任务所属周统计。
- 任务完成进度按所属周统计；递延保留原周次。
- 正确率 = 同题型正确数之和 / 总题数之和，不平均各次百分比。
- 训练 rubric 0–5 按同题型记录取平均。缺失值不算 0。
- 近 7 天与前 7 天分别汇总；阅读、听力、造句、复述、Interview、Email、Discussion 分开，不将不同量表直接混合排名。
- 周回顾根据已填标签与同题型样本给建议；至少两次相关成绩后才提示低于训练参考线，不预测官方分数。
- 模考报告独立保存，不从正确率推算 1–6 分。
- 复盘、综合模考用时列为「综合」，可自行分科填写以得到更准确的四科比例。

## 备份

网页的“更多统计字段”还可选填复盘后正确数、超时次数、作文词数与语法错误数；统计页会自动计算复盘正确率和每百词语法错误。

建议每周完成学习后导出一次完整 JSON 备份。清除浏览器数据、换浏览器、移动本地 HTML 文件都可能使原来的本地存储无法访问。备份不含云登录令牌；导入是合并，重复导入不会重复计算同一个事件。

已配置你创建的免费云项目，没有购买套餐或核实深圳余位。匿名读取已被数据库拒绝。完整的本人记录同步需要完成首次邮箱登录后验证。
